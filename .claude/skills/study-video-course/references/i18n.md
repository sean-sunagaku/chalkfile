# 多言語（英語・中国語）の講座の作り方

講座は日本語の台本が正本で、英語（en）と中国語（zh。簡体字）は「訳の上書き」を重ねて作る。声・画面の文字・図の文字・字幕・講座サイトの UI まで言語ごとに切り替わる。日本語の出力（動画・時刻・字幕・素材の音声のハッシュ）は変えない。

## 仕組み

| もの | 日本語 | 英語・中国語 |
|---|---|---|
| 台本 | `content/<講座>/<ID>.ts` | `content/<講座>/<言語>/<ID>.ts`（`LectureL10n`）と `content/<講座>/<言語>/course.ts`（`CourseL10n`）。`content/index.ts` の `TRANSLATIONS` に並べる |
| 重ね方 | — | `content/i18n.ts` の `localizeCourse`・`localizeLecture` |
| 動画の名前 | `S01` | `S01.en`（timeline・音・字幕・動画のファイル名）。Remotion のコンポジションは `S01-en` |
| 声 | VOICEVOX（`content/voices.ts` の `VOICES`） | Kokoro-82M（`KOKORO`。手元で動かす `scripts/tts_kokoro.py`、Apache-2.0） |
| 読みの確認 | `.work/kana/<ID>.txt`（カナ） | `.work/kana/<ID>.<言語>.txt`（音素）と、聞き取りの点検 `uv run scripts/check_speech.py <key>` |
| 書体 | テーマの書体 | 英語はテーマの書体、中国語は日本語の書体の代わりに Noto Sans SC（`content/themes.ts` の `fontsFor`） |
| 部品の決まった文字 | `src/i18n.ts`（日本語は元の文字のまま） | 同じファイルの en・zh |
| サイトの決まった文字 | `site/i18n.ts`（日本語は元の文字のまま） | 同じファイルの en・zh |
| サイトの URL | `/chalkfile/<講座>/` | `/chalkfile/en/<講座>/`・`/chalkfile/zh/<講座>/`（一覧は `/chalkfile/en/`・`/chalkfile/zh/`） |
| 動画の置き場所 | 講座サイト（`site/dist/<講座>/media/`） | `site/config.json` の `media` の向き先（いまは手元で確かめるための仮の場所。公開先は chalkfile.com の `/media/` に移る。下の「動画の置き場所と公開」） |

- 言語の切り替えは、講座ページの上の帯と一覧ページの見出しの横。訳のある講座はその講座の訳へ、無い言語はその言語の一覧へ飛ぶ。`<link rel="alternate" hreflang>` も出す
- 訳の一覧ページには、まだ訳していない講座を「日本語だけ」で並べる。日本語の一覧のカードには、訳のある言語の札（English・中文）が付く
- 読む教材（`material`）と章の計画（`syllabus`）は、まだ日本語だけ（訳の講座には出さない）

## 訳の書き方

```ts
// content/pstack-comedy/en/P01.ts（見本。中国語は zh/P01.ts）
export const P01: LectureL10n = {
  source: 'f82fd84b77a0',            // 訳したときの日本語の台本の指紋（bun scripts/i18n.ts stamp が書く）
  title: 'What is pstack?',
  summary: '…',
  docs: [{ title: '…' }],            // 日本語と同じ数・同じ順（URL は日本語のもの）
  quiz: [{ q: '…', choices: ['…'], explain: '…' }],  // 答えの番号は日本語のもの
  takeaways: ['…'],
  scenes: [{ kind: 'opening', title: 'What is pstack?', lines: [ … ] }, … ],  // 日本語と同じ数・同じ種類・同じ順
};
```

- 画面の要素（items・cards・nodes・rows・steps など）は、日本語と同じ数で、順に重ねる。色・アイコン・座標・URL は日本語のものを使い、文字だけを書く。数が違うと止まる
- 台詞（`lines`）は丸ごと書き直す。数が日本語と違う場面は、その場面の要素の `at`（`textAt`・`subAt`・`revealAt`・`showAt`・`focus` も）を全部書く（書き忘れると止まる）。できれば台詞の数を日本語と同じにして、要素が出る台詞を合わせる
- 概念カード（`concepts`）の `ja` は「その言語の名前」として上書きする（英語の名前は `en`）
- `s` は読み上げ用の文。英語は、そのままで読める略語（`AI`・`API`・`IDs`・`A2A`）はそのまま、読めない略語だけ空けて書く（`P R`・`C L I`）。**A で始まる略語を空けると、A が冠詞の a（ɐ）と読まれる**（2026-11-02 に音素で確かめた）。`ReAct` → `React`、スラッシュを外す。中国語の中の英語の語も同じ。中国語の多音字の直しは `content/reading.ts` の `ZH_PHRASES`（例: 数のあとの「行」は háng）
- 長さ: 字幕が 2 行に収まるよう、英語は 1 台詞 150 字、中国語は 60 字まで。見出しは英語 44 字・中国語 24 字まで
- 英語に日本語の句読点（、。「」・）を入れない。中国語に「・」（日本語の中黒）を入れない（「、」か「·」）。訳し残しは点検が止める（英語は仮名・漢字・全角の記号、中国語は仮名と、日本語とまったく同じで漢字が 3 字以上の文。1〜2 字の同じ語（人・秒・命令）は数えないので、静止画で見る）
- 事実（先生の説明・数字・名前・画面の正しい名前・クイズの答え・出典）は日本語の台本と同じにする。出典の文章を写さない・訳して載せない（台本から訳す。[rights.md](rights.md)）
- お笑いは直訳しない。言葉遊びは言語ごとに作り直す（[comedy.md](comedy.md) の「訳すとき」）

章ごとに並行して訳すときは、講座の `course.ts` に並べる前に 1 本ずつ確かめる:

```bash
bun scripts/i18n.ts try superagent-comedy en S03   # 重ね方・訳し残し・安全の点検・長さ
bun scripts/i18n.ts stamp 'S03.*'                  # 訳したときの台本の指紋を書く
bun scripts/i18n.ts status                         # 訳の表（訳あり・台本が変わった・未訳）と訳し残し
```

日本語の台本を直すと、その訳は「台本が変わった」になる（`check_content.ts` が注意を出す）。訳を見直してから `stamp` する。

## 声（Kokoro）

`content/voices.ts` の `KOKORO`。2026-11-02 に、同じ文を全部の候補の声で読ませ、Whisper（medium）で聞き取りと声の高さを比べて選んだ。

| 役 | 英語（Kokoro-82M） | 中国語（Kokoro-82M-v1.1-zh） |
|---|---|---|
| 先生（説明・ツッコミ） | af_heart（ツッコミは速さ 1.1） | zf_019（ツッコミは速さ 1.1） |
| ボケ（ずんだもん） | af_bella（涙声は速さ 0.9） | zf_092（涙声は速さ 0.9） |
| 天の声 | bm_george（イギリス英語の男性） | zm_031 |
| 呼び込み | am_fenrir | zm_029 |

- 名前: 英語は Zundamon・Teacher・Narrator、中国語は俊达萌・老师・旁白。ずんだ餅は zunda-mochi・毛豆麻糬
- 訳の講座のずんだもんは、VOICEVOX:ずんだもんの声ではない。講座の `sourceNote` にそう書く。クレジットは動画の終わりとサイトに「Kokoro-82M（声の名前）」で出る（`creditsIn`）
- Kokoro はモデルの重みが Apache-2.0。中国語の声は、データ会社の LongMaoData が許諾したデータで学習したもの（モデルカード）。英語の辞書に無い語は espeak-ng（GPL-3.0）で補うが、手元の道具として使うだけで配らない
- 初めて動かすときに、`uv` が Python の道具を、Hugging Face からモデルの重みを取ってくる（数百 MB）

## 作る順番

```bash
bun scripts/synth.ts P01.en P01.zh                  # 声と時刻（足りない台詞だけ Kokoro でまとめて読む）。'P01.*'・'*.en' も使える
uv run scripts/check_speech.py P01.en P01.zh        # Whisper で聞き取り直して、読み間違いと中国語の多音字の読みを一覧にする
uv run --locked --group audio python scripts/mix.py P01.en P01.zh
node scripts/stills.ts P01.en P01.zh --mid         # 静止画（字幕つきは --captions）
CAPTIONS=1 bash scripts/render.sh P01.en P01.zh     # site/media/P01.en.mp4・P01.en.cc.mp4・P01.en.jpg
bun scripts/build_site.ts                           # site/dist/en/… と site/dist-media/en/…
bun scripts/check_overlap.ts pstack-comedy --lang=en   # 英語の訳と出典のページを単語の並びで比べる
```

- 聞き取りの点検は「要確認」の台詞を人が読む。同じ音の別の字（不／布）や固有名詞（pstack・poteto）でも上がる。違う読みは `s` か `ZH_PHRASES` で直す
- 静止画は、英語は文が長くなりやすいので、カード・表・図の文字のはみ出しを全部見る。中国語は字形（Noto Sans SC）を見る

## 動画の置き場所と公開

**決定（2026-11-02、本人。SUN-1647・P-SUN-84 の M2）**: 公開先は chalkfile.com の Cloudflare Worker 1 本にする。サイトも動画の受付（`/media/`）も同じ Worker が配り、動画は GitHub Releases に置いて、Worker が範囲（Range）を中継して 206・`video/mp4` で返す（サイトと動画が同じ origin なので、アプリ内保存の作りはそのまま使える）。公開は GitHub Actions ＋ wrangler。言語ごとの GitHub Pages のサイトは使わない。

M2 の配信基盤:

- 公開は `publishLangs` にある言語だけ（現在ja）。`build_site.ts` が未公開のページ・切替・hreflangを出さない。保存cacheは明示削除まで保持する。
- 動画は `site/media-manifest.json` の `/media/<言語>/<講座>/<ID>[.cc].<SHA-256>.mp4`。`media.url` は同じoriginの `/media/en/`・`/media/zh/` にそろえる。言語ごとのPagesやdist-mediaは作らない。ポスターは講座ページ側の静的assets。
- Releasesを直接ブラウザへ返さず、同じoriginのWorkerでRange・MIME・download headerを処理する。Workerとサイトの許可リストを共有し、旧hashはretainedとして残す。
- strict buildは公開assetの存在/サイズ、手元のhash、静的assetsの2万files/25MiBとMP4非混入を点検する。公開はActions/Wrangler、scripts/legacy/deploy_pages.shは旧Pagesの案内専用。

## 素材とオフライン保存

- 素材のブランチ（`materials`）には、訳の言語の台詞の音声（Kokoro の出力）も、講座ごとのフォルダに一緒に入る（名前は文と声から決まるので重ならない）。`bun scripts/materials.ts pull --videos` はReleasesの一覧とhashを照合して動画を取り出す。現在のpush/pullは日本語を対象とし、M3の公開は別途進める
- オフライン保存は講座 × 言語ごと（保存の ID は `en/pstack-comedy` のように言語が頭に付く）。保存できる動画は同じoriginの `/media/<言語>/<講座>/` にあるhash付き動画で、言語・講座・hashが一致するものだけ（`site/offline-shared.ts`）
- 保存機能のエラーは、ページの言語で返す（`site/sw.ts` の `MESSAGES`）

## 確かめること

- `npm run typecheck`・`npm test`・`bun scripts/check_content.ts`（訳し残しも止める）・`bun scripts/i18n.ts status`
- `bun scripts/build_site.ts --strict` → `npm run test:browser`（`tests/browser/i18n.spec.ts`: 言語の切り替え・375px・英語の講座の保存とオフライン再生と Range・字幕の切り替え・お笑い版の保存）
- `ffprobe` の長さが `timeline.json` の `durationInFrames / 30` と合う（訳の動画も）
- 日本語の動画が変わっていないこと: 日本語の静止画を、多言語にする前のコードで描いたものと比べる（同じ条件で描くとバイト単位で同じ）
