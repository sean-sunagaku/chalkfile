# お笑い版（掛け合いで進む講座）の作り方

真面目な講座と同じ中身を、ボケ・ツッコミ・天の声の掛け合いで見せる講座の作り方。見本は `content/nudge-comedy/W01.ts`（ナッジ講座 第 1 章のお笑い版。中身と出典は `N01` と同じ）。

## いちばん大事な考え方

笑いのネタは、学ぶ中身から取る。本題と関係ないギャグは、笑っている間に本題が止まるので、増やすほど学びが薄くなる。

- **ボケ**: やってはいけないことを、自信満々に全力でやる（悪い例を演じる）
- **ツッコミ**: それに、講座の言葉で名前をつける（「監禁です」→ 画面に「強制」）
- すると、**笑った瞬間が、その考え方が分かった瞬間**になる。ズレに気づくには、正しい形を知っている必要があるから

ボケを選ぶ基準は「この章の中身を知らないと笑えないか」。知らなくても笑えるギャグは、つかみ以外では削る。

## 守ること

- ボケや大げさなツッコミで言った間違いは、同じ場面の中で必ず正しい言い方に戻し、画面にも正しい形を出す（表の「正しい名前」の列など）。間違いを覚えて帰らせない
- ツッコミの強い言葉（監禁・詐欺・犯罪のような罪の名前）は、大オチの後に「いや、言い過ぎました。正しい名前は、…」と言い直す。「犯罪とまでは言いませんけど」は「ほぼ犯罪」とも聞こえるので使わない。表の列の見出しも「ツッコミ（大げさ）」にする。悪い役にした打ち手（強制・お金）が、場面によっては普通の道具であることも 1 行で言う
- 先生や天の声は、ツッコミの言葉を事実のように言い直さない（「一万ポイントは買収でした」→「一万ポイントは、買収……ではなく、お金の打ち手でした」。言い直し自体を笑いにする）
- 真面目版の「この講座では、…と考えます」を、掛け合いにするときに落とさない。研究者の基準と講座の考え方を分ける
- 講座の `disclaimer` に「ボケの台詞は、わざと間違えています」と書く（動画のはじめと終わり、サイトに出る）。ずんだもんの規約（東北ずん子・ずんだもんプロジェクトの音源利用規約）は、故意に虚偽や誤解を招く内容を作る・広める目的の利用を禁じている。訂正と注意書きがあるから、教える目的の使い方になる
- 笑う対象は、ボケ自身の失敗と「人間あるある」だけ。見ている人・実在の会社や人・属性はいじらない
- 芸人さんのネタや決め台詞は借りない。借りるのは型・間・編集の技術だけ
- 事実（先生と天の声の台詞、画面の文字）は、真面目版と同じく出典で確かめる。笑いのために数字や研究の言い方を強めない
- 読む教材・出典・確認クイズは真面目なまま。笑いは動画の中だけ（お笑い版の講座は、教材を真面目版にリンクする）

## 配役と声

| 役 | 声（`v`） | 話し方 |
|---|---|---|
| ボケ（ずんだもん） | `zundamon`、へこんだとき `zundamon-cry`（なみだめ） | 新人。数字を上げたい気持ちが強すぎて、毎回やりすぎる。悪気はゼロ |
| 先生（説明） | 省略（`narrator` = 真面目版の講師の声） | 冷静。説明は真面目版と同じ中身 |
| 先生（ツッコミ） | `tsukkomi`（同じ No.7 を少し速く、抑揚を強く） | 敬語で短く、名前をつける（「詐欺です」）。VOICEVOX は標準語のアクセントで読むので、関西弁のツッコミは使わない |
| 天の声 | `tennokoe`（青山龍星・しっとり）。呼び込みは `announcer` | 淡々と、真実や先のことをばらす（「中立だと思っていたのは、本人だけであった」） |

講座の `cast` に、声ごとの名前と色を書く。字幕の焼き込みの帯に名前の札が出て、サイトの台本と字幕は「ずんだもん：…」になる。

声のクレジットは、レクチャーで使った声だけが動画のエンディングに出る（`src/generated/lecture-credits.json`）。講座サイトのクレジットの行は全講座で共通（講師と呼び込み）なので、ほかの声は講座の `sourceNote` にも書く（`ボケの声は VOICEVOX:ずんだもん。…`）。

## 間・効果音・BGM（台詞の項目）

| 項目 | 使い方 |
|---|---|
| `pause: -0.15` | 台詞の後の間（0.3 秒）を詰める。ボケの台詞に付けると、次のツッコミが食い気味に入る（最短 0.05 秒） |
| `pause: 0.5〜0.9` | ボケの後の「間」。スベった空気・溜め |
| `sfx: 'harisen'` | ツッコミの台詞の頭で「パシッ」。名前ツッコミと大オチに。毎回は鳴らさない |
| `sfxAfter: 'chin'` | 台詞の後の間に「チーン」（スベった・全滅した） |
| `sfxAfter: 'drumroll'` + `pause: 1.5` | 溜めのドラムロール（1.5 秒で「ジャン」）。期待させて、次の台詞で裏切る |
| `sfx: 'deden'` | 衝撃の「デデーン」。天の声の大げさな宣言に |
| `sfxAfter: 'zuko'` | ずっこけの「ヒューン」。予想外の告白（「……私です」）の後に |
| `bgm: 'cut'` / `bgm: 'back'` | BGM を止めて急に真面目にし、一番大事な一文を言う。`back` が無ければ場面の終わりで戻る |

効果音は `scripts/build_music.py` がコードで合成する（外の音源を使わない）。足したら `--only <名前>` で、その効果音だけを書き出せる。笑い声の効果音は入れない（合成だと不自然で、「ここで笑って」の押しつけに見える）。

## 笑いの型

| 型 | 例（W01） | 効くところ |
|---|---|---|
| あるある | 「通知の許可、とりあえず、許可しないを押す人、いますよね」「……私です」 | つかみ・困りごと |
| 名前ツッコミ | 監禁です／買収です／詐欺です（画面に強制・お金・ダークパターン） | 用語を覚える |
| 三段オチ | 「〇〇です」を 3 回くり返し、4 つ目は「思いつかなかったのだ」 | リズム・要点の強調 |
| 言葉のズレ | 「ひじでつつけば、オンにしてくれるのだ？」「物理的に、つつかないでください」 | 語源と定義 |
| 天丼 | 「百パーセント」「虫眼鏡ボタン」「地味」を場面をまたいで回収する | 復習・最後の回収 |
| 急にシリアス | BGM を止めて「その四つ目こそが、ナッジである」 | 核心を刺す |
| メタ | 「止めたら、ぼくの出番が減るのだ」「止めてください」 | 演習への橋渡し |

## 章のリズム

真面目な章の流れ（困りごと → 考え方 → 良い例・悪い例 → 演習 → 振り返り）に、そのまま重ねる。

- 冒頭 15 秒のつかみ（天の声の説明とボケの第一声）
- 30 秒に 1 回クスッ、2〜3 分に 1 回ドッ。その間をもたせるのは、ボケの数ではなく掛け合いのテンポ
- 大きな笑い（悪い例のボケの連打 → 大オチ）の直後に、BGM を止めて本題の一文
- 数字や研究の場面は、ほぼ真面目にする（緊張をためる）
- 振り返りで天丼を回収し、ボケが少しだけ成長して終わる（最終章で、ボケが初めてちゃんとできる流れにすると、見ている人の成長と重なる）

## 長さ

掛け合いは台詞の行が増える。真面目版をそのまま掛け合いにすると 1.4 倍ほどになった（W01: 最初の台本で 9.7 分 → 実践手順の場面を演習にまとめ、言い回しを詰めて 8.4 分 → 事実確認の言い直しを足して 8.6 分）。真面目な説明の読点を減らすと、間が短くなってテンポが上がる。

## 事実確認

真面目版と同じく、書いた担当とは別のサブエージェントに、台本ファイルと [factcheck-brief](../../course-from-prompt/references/factcheck-brief.md) を渡す。お笑い版では、加えて「ボケと大げさなツッコミの一覧と、同じ場面で訂正できているか」「罪の名前など、法的な評価に聞こえる言葉」「見ている人や実在の人・会社をからかっていないか」を見てもらう（W01 では、上の守ることの 3 つが見つかった）。
