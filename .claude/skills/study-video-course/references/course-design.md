# 講座の組み立て

## 先に決めること

- 受講者と前提（例: Web アプリを作れる。Stripe は初めて）
- 講座が終わったらできること（ゴール 3 つ）
- 例に使う架空のアプリ（名前・プラン・値段）。講座の最初から最後まで同じものを使う

決めたら、セクションとレクチャーの並び（タイトルと 1 行の中身）を頼んだ人に見せてから台本に入る。

## 講座の型と大きさ

長さと本数の目安は、この表だけに書く（ほかの文書はここへリンクする）。今ある講座の実際の大きさから決めた。

| 型 | 見本 | 本数 | 1 本の長さ | 場面 | 台詞 |
|---|---|---|---|---|---|
| レクチャーの講座 | `stripe-billing` | 10〜15 本（セクション 4〜6。合計 40〜60 分） | 3〜6 分 | 7〜12 | 25〜50 行 |
| 章立ての講座（読む教材つき） | `nudge-product`・`uiux-engineers`・`indie-marketing` | 5〜8 章 | 6〜8 分（長くても 10 分） | 12〜16 | 55〜70 行（読み上げ 2,100〜2,900 字） |
| お笑い版の章立て | `superagent-comedy`・`nudge-comedy` | 5〜8 章 | 7〜9 分 | 10〜14 | 80〜100 行 |
| 1 本だけの解説動画 | `pstack-comedy`・`rive-comedy` | 1 本（講座に `standalone: true`） | 4〜6 分 | 9〜12 | 55〜75 行 |

- 新しく作る講座は、どの型でもお笑いを入れる（[comedy.md](comedy.md)）。掛け合いは台詞が増え、同じ中身で 1.2〜1.4 倍ほど長くなる（W01 は、もとの N01 の 7.3 分に対して 8.6 分。最初の台本では 9.7 分だった）
- 短い入門なら、お笑い版の章立てを 1 章 3〜4 分・3 章ほどにしてもよい（`ga4-comedy`）
- 台詞の字数は読み上げ（`s`）の字数。合成すると 1 秒あたり約 6.3 字
- 1 本で言うことは 1 つの問い（「Webhook で何が届くか」「どの状態なら使わせるか」）に絞る
- 章立ての講座の計画（`syllabus.ts` の `minutes`）と、章を書く担当に渡す目安も、この表にそろえる

## 講座の分け方

概念と、特定のアプリへの当てはめを 1 本に混ぜると「どこが一般論で、どこがそのアプリの話か」が分からなくなる。分ける。

- 基礎編: 概念とデータの形、架空のサンプルで作る流れ、お金・法律・規約。公開する
- 実践編: 基礎編の考え方を、特定のアプリの設計に当てはめる。仕事の情報が入るので非公開のまま

## 1 本のレクチャーの型

| 場面 | 中身 |
|---|---|
| `opening` | 呼び込み（「レクチャー 2。Stripe の登場人物。」を announcer の声で）と、一言の導入 |
| `goals` | このレクチャーのゴール 3 つ（「〜が言える」「〜を図で説明できる」） |
| 本題 4〜8 場面 | 図・表・コード・比較で 1 つずつ。下の「場面の選び方」 |
| `quiz`（任意） | ○×で誤解を潰す。`hold` で考える時間を取る |
| `recap` | まとめ 3 つ（ゴールと対にする） |
| `ending` | 次のレクチャーの予告（`next`）。最後のレクチャーは `closing` に一言 |

最後のレクチャーは、○×クイズで全体の誤解を潰す → いちばん伝えたいこと（`big`）→ 次の一歩（`points`）→ `ending` の `closing`。

## 場面の選び方

| 言いたいこと | 場面 |
|---|---|
| 用語を並べて覚えてもらう | `concepts`（カード。ID の頭の文字なども） |
| 誰から誰へ何が届くか | `sequence`（登場人物と矢印） |
| 仕組みの全体図 | `flow`（自由配置の図） |
| 状態とその移り方 | `states` |
| 実際のコード・JSON | `code`（行を光らせて横に注） |
| 対応表・一覧 | `table`（6 行・3 列まで） |
| 2 つのやり方の比べ | `compare`（左右と結論） |
| 一番言いたい一文 | `big` |
| 料金・手数料の計算 | `numbers` |
| 時間の流れ | `timeline` |
| 番号付きの手順・要点 | `points` |
| 画面の流れ | `phone`（アプリの画面と Stripe の支払いページ） |
| コマンドを打つところ | `terminal` |
| 参考資料の紹介 | `refs` |

## 講座サイトに出すもの（レクチャーごと）

- `summary`: 1 文の中身
- `takeaways`: 実装に効くメモ 3〜5（時点で変わることは日付付き）
- `docs`: 公式ドキュメント 3〜5
- `quiz`: 選択式 3 問（`answer` は 0 始まり、`explain` に理由）

講座（`Course`）には、`title`（動画の右上にも出る）・`subtitle`・`headline`（`**…**` がグラデーション）・`sections`・`docsNote`・`sourceNote`・`links` を書く。レクチャー ID の頭文字（`prefix`）は、[new-course.md](../../../../docs/guide/new-course.md) の表で空いているものを選ぶ（講座をまたいで重ならない）。
