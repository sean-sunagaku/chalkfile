# 名前と公式ドキュメントの使い方（著作権・商標）

講座は、製品の名前を出し、公式ドキュメントを読んで作る。どちらも、ここの決まりを守れば使ってよい。法律の助言ではないので、迷うとき（特に講座でお金を取るとき）は専門家に確かめる。

## 公式ドキュメント（著作権）

著作権が守るのは、文章・図・写真・動画といった「表現」。事実・仕組み・手順・考え方は守らない（著作権法 2 条 1 項 1 号）。API の名前・フィールド名・取りうる値・既定値・料金の数字も事実で、プログラムの言語・規約（インターフェース）・解法も保護の外（10 条 3 項）。

してよいこと:

- 公式ドキュメントを読んで確かめた事実を、自分の言葉と自分の順番で説明する
- API の名前・フィールド名・イベント名・エラーコードをそのまま書く
- 出典の URL を載せる（レクチャーの `docs`）。写していなくても、どこで確かめたかは残す

してはいけないこと:

- 文章を写す。言い回しと段落の順番をなぞって、語尾だけ変える
- 英語のドキュメントを訳して載せる（訳すのにも権利者の許しが要る。27 条）
- 図・画面写真・動画・イラストを載せる。なぞって描き直す
- ドキュメントの長いサンプルコードを、ライセンスを確かめずに載せる

引用するときは、必要な分だけ短く、自分の説明が主で、かぎかっこなどで分け、出典を言う（32 条・48 条）。台本では基本的に引用しない。

コードの例:

- API の呼び方は誰が書いても似た形になる。サンプルの値（名前・金額・ID・メール）は自分で作り、最小限に書く
- 長いサンプルを使いたいときは、そのコードのライセンス（SDK やサンプルのリポジトリは MIT などが多い）を確かめ、表示の条件を守る

ドキュメントのライセンス:

- 多くの公式ドキュメントは、転載や改変の許しを出していない。普通の著作物として扱う
- 中には CC BY などで改変を許すものもある（例: MDN は CC BY-SA 2.5）。そのときも、表示と継承の条件を守る
- 法令・告示・判決は著作権の対象外（13 条）。官公庁の解説ページは普通の著作物として扱う

## AI に読ませて書くとき

文化審議会 著作権分科会 法制度小委員会「AI と著作権に関する考え方について」（令和 6 年 3 月 15 日）の整理では、AI で作ったものも、普通と同じく「既存の著作物と創作的な表現が似ていて（類似性）」「それをもとに作った（依拠性）」なら侵害になる。AI に読ませた文書は、もとにしたと見られやすい。だから、似ていないことが大事。

- 公式ページを AI に読ませるのは、事実を確かめるため。台本の文章は、確かめた事実から新しく書く
- 台本ができたら `bun scripts/check_overlap.ts <講座 ID>` で、レクチャーの `docs` の公式ページと突き合わせる。空白を除いて 16 文字以上続けて同じところを出すので、自分の言葉に書き直す
- 日本語版のページと比べる（Stripe は `--query=locale=ja-JP`）。英語のページしか比べられないときは、訳して写していないかを人が読んで確かめる（スクリプトが一覧に出す）
- ページの題名（`docs` の `title`）は比べない。題名で出典を示すのはよい

Stripe 講座での結果（2026-10-30）: 台本の文字列 1,649 個と、出典の公式ページ 43 本（Stripe のページは日本語版）で、16 文字以上の一致はなし。12 文字まで下げると 16 か所出るが、「ダッシュボードの設定で」「特定商取引法に基づく表記」のような決まった言い方だけだった。英語のまま比べた Apple の 3 本は、日本語版（`developer.apple.com/jp/`）とも比べて一致なし。Stripe CLI のページは日本語版が無く、台本ではコマンドと、その表示を見せているだけ。

## 製品の名前（商標）

- 講座の中身を言うために、製品の名前を文字で書くのはよい（「Stripe サブスク課金 基礎講座」）
- 公式・認定・提携・推薦と受け取れる書き方をしない。講座の `disclaimer` に「○○社とは関係のない非公式の講座」と書く（動画のはじめと終わり、サイトに出る）
- ロゴ・アイコン・社名の書体を使わない。製品の名前を、自分の製品名・テーマ名・ドメイン・アカウント名に入れない
- 会社ごとの決まりがあれば読む。例: Stripe の Marks Usage Terms は、文字で正確に言及することは認め、推薦をにおわせる使い方・ロゴの改変・自社の商標への組み込み・混同させる使い方を禁じている
- 見た目を寄せるのは色の雰囲気まで（[theme.md](theme.md)）

## 画面と画像

- 公式サイト・管理画面・アプリの画面写真は載せない。画面は図として自分で描く（`phone` の場面。中身は架空の「サンプルアプリ」）
- 画像は自分で作ったもの（Remotion で描いたもの）を使う。人の写真・イラスト・素材は、使ってよい条件を確かめたものだけ
