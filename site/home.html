__COURSES__

作り方

動画は、台本のデータから毎回作り直せるようにしています。手順と、画面と話し方の決まり、調べ方は、Claude Code のスキルにまとめてあります。

  1. 調べる公式ドキュメントと一次情報を読み、確かめた日と版を残す
  2. 台本と図を書く場面ごとの台詞と、台詞に合わせて出す図を TypeScript で書く
  3. 声を付けるVOICEVOX で読み上げ、読みのカナを全部確かめる
  4. 動画にするRemotion で映像を書き出し、BGM と効果音を合わせる
  5. 公開する講座サイトを組み立てて GitHub Pages に出す
README（作り直す手順） Claude Code のスキル
