# 個人開発者のためのマーケティング

誰の・何の課題を・なぜ自分のサービスで解決するのか

- 講座 ID: `indie-marketing`
- 受講者: 自分の Web サービスやアプリを作っている（作りたい）エンジニア・個人開発者。マーケティングは初めて
- 例に使う架空のサービス: 架空の請求書アプリ「サンプル請求書」（個人で働く人が、毎月の請求書を作る。月 500 円のプランの仮の例）

## 到達目標

1. マーケティングを「誰の・何の課題を・なぜ自分のサービスで解決するのか」から説明し、価値の仮説を立てて確かめられる
2. 顧客理解・課題の検証・対象顧客・ポジショニング・価値の伝え方・価格・集客経路・利用開始から継続・効果測定を、自分のサービスに当てはめられる
3. 「対象顧客 → 提供価値 → 発信内容 → 集客経路 → 小さな検証計画」を 1 枚にまとめ、売上と利益を分け、少ないデータで断定せずに検証を回せる

最後の実践: 自分のサービスについて「対象顧客 → 提供価値 → 発信内容 → 集客経路 → 小さな検証計画」を 1 枚にまとめる（第 8 章）

## 前提知識

- 自分のサービス（作りかけ・案でもよい）がある
- 数字の割合（%）が分かる

### 第 1 章 マーケティングとは何か（`mkt-01`）

問い: 広告や SNS の前に、何を決めるべきか？

学習目標:

- マーケティングを宣伝より広く説明できる
- 誰の・何の課題を・なぜ自分のサービスで、に答えられる
- 価値の仮説を 1 文で書ける

前提知識:

- なし

動画の構成:

| 流れ | 中身 |
| --- | --- |
| 困りごと | サンプル請求書を公開して告知したが、登録 12 人・2 週間後も使うのは 2 人（仮の数字） |
| 考え方 | マーケティングの定義（AMA・日本マーケティング協会）、3 つの問い、ジョブ理論と代わりの手段 |
| 良い例・悪い例 | サイトのトップの一文: 機能の一覧（悪い例）／誰の・課題と変化・乗り換えやすさ（良い例）。○×クイズ |
| 実践手順 | 価値の仮説を型に沿って 1 文で書く。講座の約束（売上と利益・少ないデータ） |
| 演習 | 自分のサービスの価値の仮説を 1 文で書く（5 分） |
| 振り返り | 要点 3 つと、講座の地図 |

実践課題の案: 自分のサービスの価値の仮説を 1 文で書き、確かめる相手を決める

### 第 2 章 顧客理解と課題の検証（`mkt-02`）

問い: その課題は本当にあり、どれくらい困っているのか？

学習目標:

- 未来の意見ではなく、過去の具体的な行動を聞くインタビューができる
- 課題の頻度・深さ・今の代わりの手段を聞き取れる
- 聞いた結果で、価値の仮説を直せる

前提知識:

- 第 1 章

動画の構成:

| 流れ | 中身 |
| --- | --- |
| 困りごと | 知人に聞いたら「いいね、使いたい」と言われたのに、公開しても使われない |
| 考え方 | 顧客開発、過去の行動を聞く、課題の頻度と深さ、代わりの手段にかけているお金と時間 |
| 良い例・悪い例 | 「このアプリ使いますか？」（悪い例）／「先月の請求書は、どうやって作りましたか？」（良い例） |
| 実践手順 | 聞く相手を 5 人選び、質問を作り、話を聞き、仮説を直す |
| 演習 | インタビューの質問を 5 つ作る |
| 振り返り | 褒め言葉は、検証の結果ではない |

実践課題の案: インタビューの質問表（5 問）と、聞いた結果のまとめ・仮説の直し

主な出典:

- Steve Blank（2010）「Teaching Entrepreneurship – By Getting Out of the Building」 https://steveblank.com/2010/03/11/teaching-entrepreneurship-%E2%80%93-by-getting-out-of-the-building/ （実務の指針・2026-10-30 確認）
- Rob Fitzpatrick（2013）「The Mom Test」 https://www.momtestbook.com/ （実務の指針・2026-10-30 確認）

### 第 3 章 対象顧客の選び方とポジショニング（`mkt-03`）

問い: 最初に、誰に・何として選ばれるサービスにするか？

学習目標:

- 最初の対象顧客を、狭く具体的に選べる
- 代わりの手段と比べた、自分だけの特徴と価値を書ける
- ポジショニングの 1 文を作れる

前提知識:

- 第 1〜2 章

動画の構成:

| 流れ | 中身 |
| --- | --- |
| 困りごと | 「誰でも使える」と言うほど、誰にも刺さらない |
| 考え方 | 対象顧客の絞り方、ポジショニングの要素（代わりの手段・独自の特徴・価値・対象・カテゴリー） |
| 良い例・悪い例 | 「多機能な請求書アプリ」／「取引先が少ないフリーランスのための、写して作る請求書」 |
| 実践手順 | 代わりの手段の表を作り、選ばれる理由を書き出す |
| 演習 | 自分のサービスのポジショニングの 1 文 |
| 振り返り | 絞ることは、捨てることではなく、最初の一歩 |

実践課題の案: 代わりの手段との比較表と、ポジショニングの 1 文

### 第 4 章 価値の伝え方（`mkt-04`）

問い: サイトやストアで、価値を一瞬で伝え、試してもらうには？

学習目標:

- 機能ではなく、課題と変化で伝える文を書ける
- 根拠のある表現と、誇張（優良誤認のおそれ）を見分けられる
- 最初の行動（試す・登録する）までの手間を減らせる

前提知識:

- 第 1〜3 章

動画の構成:

| 流れ | 中身 |
| --- | --- |
| 困りごと | サイトを見に来た人が、すぐ帰ってしまう |
| 考え方 | 見出し・説明・証拠・最初の行動、景品表示法とステルスマーケティングの規制 |
| 良い例・悪い例 | 根拠のない「No.1」「作業時間 5 分の 1」／測った事実と利用者の声（表示の明記つき） |
| 実践手順 | トップの一文・3 つの利点・最初の行動を書き直す |
| 演習 | 自分のサイトかストアの説明文を書き直す |
| 振り返り | 伝える言葉は、話を聞いた相手の言葉から作る |

実践課題の案: サイトかストアの説明文の書き直し（見出し・利点・証拠・最初の行動）

主な出典:

- 消費者庁（—）「優良誤認とは」 https://www.caa.go.jp/policies/policy/representation/fair_labeling/representation_regulation/misleading_representation/ （公式・法令・規格・2026-10-30 確認）

### 第 5 章 価格と、売上と利益（`mkt-05`）

問い: いくらで売れば、相手にとって納得でき、自分に利益が残るか？

学習目標:

- 価値・代わりの手段・費用の 3 つから価格の幅を考えられる
- 手数料・サーバー代・税金を含めて利益を計算できる
- 無料プランと有料プランの境目を設計できる

前提知識:

- 第 1〜4 章

動画の構成:

| 流れ | 中身 |
| --- | --- |
| 困りごと | 安くすれば使われると思ったが、利益が残らない |
| 考え方 | 価格の決め方、売上と利益、手数料（決済・アプリストア。日本の App Store は 2025 年 12 月に条件が変わった）、価格の聞き方 |
| 良い例・悪い例 | 費用を足して決めた価格／代わりの手段と価値から決めた価格 |
| 実践手順 | 利益の計算表を作り、価格の候補を 3 つ比べる |
| 演習 | 自分のサービスの利益の計算表 |
| 振り返り | 値段は、あとから変えられるが、上げるのは難しい |

実践課題の案: 利益の計算表（売上・手数料・費用・利益）と、価格の候補 3 つの比較

主な出典:

### 第 6 章 集客経路の選び方（`mkt-06`）

問い: 対象の人は、どこで課題に気づき、何を探しているか？

学習目標:

- 検索・コミュニティ・SNS・紹介・ストア・メールなどの経路の特徴を説明できる
- 自分が続けられる経路を 1〜2 つに絞れる
- 広告メールの同意（オプトイン）などのきまりを守れる

前提知識:

- 第 1〜5 章

動画の構成:

| 流れ | 中身 |
| --- | --- |
| 困りごと | あらゆる SNS に投稿して、疲れて続かない |
| 考え方 | 経路の種類、対象の人が課題に気づく場所、検索の基本、特定電子メール法 |
| 良い例・悪い例 | 全部の経路に少しずつ／対象の人がいる 1 つの経路に絞って続ける |
| 実践手順 | 経路の候補を並べ、手間・届く相手・続けやすさで選ぶ |
| 演習 | 自分の経路を 2 つ選び、1 か月の発信の計画を立てる |
| 振り返り | 経路は、相手の居場所と、自分の続けやすさで選ぶ |

実践課題の案: 集客経路の比較表と、1 か月の発信の計画

### 第 7 章 利用開始から継続まで（`mkt-07`）

問い: 登録した人が、価値を感じて使い続けるまでに、どこで止まっているか？

学習目標:

- 登録から「価値を感じた瞬間」までの流れを定義できる
- 流れの段階ごとの人数を見て、止まっている所を見つけられる
- 続ける理由を作る施策を考えられる

前提知識:

- 第 1〜6 章

動画の構成:

| 流れ | 中身 |
| --- | --- |
| 困りごと | 登録は増えたが、2 週目に戻ってくる人が少ない |
| 考え方 | 利用開始（アクティベーション）・継続（リテンション）、段階ごとの人数（ファネル） |
| 良い例・悪い例 | 登録だけを数える／最初の請求書を送った人を数える |
| 実践手順 | 価値を感じた瞬間を定義し、そこまでの手間を減らす |
| 演習 | 自分のサービスのファネルを書き、止まっている段階を選ぶ |
| 振り返り | 集客より先に、続く仕組みを直す |

実践課題の案: ファネルの図（段階・人数）と、止まっている段階の改善案

主な出典:

- Dave McClure（2007）「Startup Metrics for Pirates」 https://www.slideshare.net/dmc500hats/startup-metrics-for-pirates-long-version （実務の指針・2026-10-30 確認）

### 第 8 章 効果測定と 1 枚の計画（`mkt-08`）

問い: 少ないデータで、何を・どう測って、次を決めるか？

学習目標:

- 測る数字と、判断のライン・期間を先に決められる
- 少ないデータを幅（信頼区間）で読み、断定を避けられる
- 対象顧客 → 提供価値 → 発信内容 → 集客経路 → 小さな検証計画を 1 枚にまとめられる

前提知識:

- 第 1〜7 章

動画の構成:

| 流れ | 中身 |
| --- | --- |
| 困りごと | 施策を毎週変えて、何が効いたのか分からない |
| 考え方 | 仮説・指標・判断のライン、少ないデータの読み方、売上と利益で判断する |
| 良い例・悪い例 | 3 日見て「効いた」／期間と人数と判断のラインを先に決める |
| 実践手順 | 1 枚の計画を埋め、小さな検証を 1 つ回す |
| 演習 | 自分のサービスの 1 枚の計画を完成させる |
| 振り返り | 講座全体の振り返りと次の一歩 |

実践課題の案: 1 枚の計画（対象顧客・提供価値・発信内容・集客経路・小さな検証計画）

主な出典:

- NIST（—）「NIST/SEMATECH e-Handbook of Statistical Methods 7.2.4.1 Confidence intervals（割合の信頼区間）」 https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm （研究・学術・2026-10-30 確認）
- Eric Ries（2011）「The Lean Startup: Principles」 https://theleanstartup.com/principles （実務の指針・2026-10-30 確認）
