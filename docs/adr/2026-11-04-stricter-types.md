# 配列の範囲と、省略する項目も型で確かめる

- 状態: 採用
- 日付: 2026-11-04

## 決定

root の `tsconfig.json` で `noUncheckedIndexedAccess` と `exactOptionalPropertyTypes` を有効にする。現行の動画・台本・サイト・Worker・道具・テストは、この設定を引き継ぐ。

配列や辞書から取り出した値は、存在を確かめてから使う。色やコマンド行のように長さの決まっているものは、タプルで表す。添字の範囲を既に確かめているループや、必ずある正規表現の捕捉群は、その根拠を読み手が追える形で扱う。

任意の項目は、原則として省く。「訳を重ねるときに値を消す」「親から受け取った任意の色を既定の色に戻す」「道具の引数を既定値にする」など、既に `undefined` を明示していた契約だけは、型にもその意味を書く。外のライブラリが省略を求める項目は、値があるときだけ渡す。

テストの見本に要る値は `tests/support/required.ts` で確かめてから使う。不正な入力を試すテストでは、入力を欠けたまま検査へ渡す。見本の検査で先に止まり、実装の検査を通ったように見せない。

## 凍結中のコード

[旧 Pages の撤去期限](2026-11-02-legacy-pages-end-date.md)までは、次の範囲を従来の型設定で分けて検査する。元のコードと公開物の指紋は変えない。

| 設定 | 対象 |
|---|---|
| `tests/tsconfig.legacy.json` | `scripts/build_migration.ts` と、その API だけを扱う `tests/unit/legacy-migration.test.ts` |
| `site/tsconfig.legacy-sw.json` | `site/legacy-sw.ts` |

この 2 つの設定も `npm run typecheck` に含める。旧 API の実際のテストは、ほかの単体テストと同じく `npm test` が流す。現行コードの設定は緩めない。2027-05-02 以降に旧コードを撤去するとき、この設定と対象のテストも片付ける。

## 確かめ方

`npm run check` で全範囲の型と単体テストを確かめる。サイトの前後の出力、台本・教材・訳の値、音声と時刻の指紋、描画した静止画も比べる。サイトと保存の処理は `npm run test:e2e:ci`・`npm run test:e2e:real` と手元の Worker で確かめる。
