# 講座にはお笑いを必ず入れ、お笑い版の表示は少なくする

- 状態: 採用
- 決めた日: 2026-11-01（持ち主）。表示を少なくする決まりは 2026-11-02 に足した
- 関連: #5〜#8（お笑い版と、掛け合いの型）・#10（表示を少なくした）
- 書き方の決まりの正本: スキルの [comedy.md](../../.claude/skills/study-video-course/references/comedy.md)。ここには写さない

## 背景

- 2026-11-01 に、ナッジ講座のお笑い版（W01）と、Rive のお笑い版（R01）を作った。ボケ（ずんだもん）・ツッコミ（先生）・天の声の掛け合いで進む
- 持ち主が 2 本を見て、とても面白い、掛け合いがよいと評価した
- 2026-11-02 に pstack のお笑い版（P01）を見た持ち主が、お笑い版だと名乗る前置きや、中身に関係ない表示は要らないと言った

## 決めたこと

- 新しく作る講座と解説動画には、掛け合いのお笑いを必ず入れ、笑いを優先する。今ある講座を作り直すときも、comedy.md の型にそろえる
- お笑い版は表示を少なくする。お笑い版だと名乗る副題・札・前置きを出さない。1 本だけの動画は、番号と根拠の札も出さない（`standalone`）
- 事実は崩さない。先生の説明・画面の文字と数字・出典・クイズの答えは、真面目版（真面目版の無い題目は公式ドキュメント）で決めた事実のままにする

## 理由

- ボケが悪い例を全力で演じ、ツッコミが講座の言葉で名前をつけると、笑った瞬間が、その考え方が分かった瞬間になる（comedy.md の「いちばん大事な考え方」）
- 持ち主が、できた動画を見て決めた
- お笑いだと名乗らなくても、掛け合いで笑わせられる（comedy.md の「表示は少なく」）

## ほかの案

| 案 | 選ばなかった理由 |
|---|---|
| 真面目版だけにする | 持ち主が、掛け合いの形を基準にすると決めた |
| お笑いを入れるかを、講座ごとに選ぶ | 持ち主の方針は「必ず入れる」 |
| お笑い版だと分かる表示（副題・札・前置き）を出す | 持ち主が、要らないと判断した |

## 影響

- 掛け合いは、誰が話したかが分からないと笑えない。字幕を焼き込んだ版も作る（`CAPTIONS=1`）
- ずんだもんなどの声は、キャラクターの利用規約に従う。講座の `disclaimer` に、ボケの台詞はわざと間違えていると書く
- 事実確認の担当には、ツッコミの大げさな言葉を、台詞で打ち消す直しを入れないと先に伝える
- 読む教材・出典・確認クイズは真面目なまま。笑いは動画の中だけ
- R01 と W01 の日本語の動画は、表示を少なくする決まりの前に作ったまま。訳の動画は、決まりに合わせた
