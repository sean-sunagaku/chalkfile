# 別の使い手が現れるまで、workspaces と npm 公開を見送る

- 状態: 採用
- 決めた日: 2026-11-04（リファクタリングの引き継ぎ方針を記録）
- 関連: [依存の向き](../architecture/overview.md#依存の向き)

## 背景

Chalkfile は、このリポジトリの講座を作り、動画と講座サイトを公開するために使っている。共通の型と処理は `engine/core/` に集め、動画・道具・サイト・Worker の依存の向きを lint と型検査で守る形になった。

## 決めたこと

T4-05 の npm workspaces への移動と、T4-06 のエンジンの版付き npm 公開は見送る。今の `engine/`・`src/`・`scripts/`・`site/`・`worker/` の配置を使う。

別の講座集やリポジトリからエンジンを使う具体的な利用者が現れたとき、または持ち主が npm 公開を求めたときに再検討する。その際は必要な公開 API と互換性の範囲を先に決め、移動のための静かな日を設ける。ライセンスの利用者向けの説明、版の付け方、講座の置き場所も公開前に決める。

## 理由

フォルダの境界と依存の検査で、今必要な分離はできている。別の使い手がいない段階で全パスを移すと、CI・書き出し・文書の変更と公開 API の維持が増える。具体的な使い手の要件を得てから分ける方が、切り出す範囲を判断できる。

## ほかの案

| 案 | 選ばなかった理由 |
|---|---|
| 今すぐ全体を workspaces に移す | 今の利用に必要な境界は検査できており、全パスの変更に見合う利用者がまだいない |
| 今すぐ npm に公開する | 公開 API・互換性・配布の維持範囲を決める具体的な需要がまだない |

## 影響

今回のリファクタリングでは、パッケージの移動、npm 公開、changesets の導入は行わない。将来の再検討までは依存の向きと契約の検査を保つ。見送りは作業漏れと区別して進捗表へ記録する。
