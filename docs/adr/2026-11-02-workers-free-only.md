# Workers Free のままにする。Terraform・R2・有料プランを使わない

- 状態: 採用
- 決めた日: 2026-11-02（持ち主）
- 関連: Linear の P-SUN-84・SUN-1627。[配信は Cloudflare Workers と GitHub Releases にする](2026-11-02-workers-and-releases.md)

## 背景

- Chalkfile は公開の OSS。持ち主の方針は、インフラの維持費を 0 円にすること。払うのはドメイン代だけにする
- 配信を Cloudflare Workers と GitHub Releases にした。プラン・動画の置き場所・設定の持ち方と、無料の枠を超えたときの動きを決める必要があった

## 決めたこと

- Cloudflare は Workers Free のままにし、有料プランに変えない
- 動画の置き場所に R2 を使わない（Releases に置く）
- Cloudflare の設定は `wrangler.jsonc` に持ち、Terraform を使わない
- サイトに広告は、今は出さない

## 理由

2026-11-02 に確かめたこと（数字はその日のもの。今の値は公式で確かめる）:

- Workers Free の Worker の要求は、1 日 10 万回まで。超えた日はエラーで止まり、請求は来ない。費用が知らないうちに増えない
- 静的なファイルの配信は無料で、この回数の枠を使わない。枠を使うのは、Worker を先に通す `/media/*`
- 1 本を最後まで再生したとき、Worker の要求は 2 回だった。参考の値は 1 日 5 万回の再生で、保証する値ではない（[公開確認の記録](../history/2026-11-03-workers-verification.md) の「無料枠の測定」）
- R2 は、無料が 10GB まで。超えた分は有料で、止まる上限が設けられていない。費用が読めない
- 設定は `wrangler.jsonc` 1 つで足りる。Terraform を使うと、状態（state）を置く場所が要る
- 費用はドメイン代（.com で年 1,700 円ほど）だけになる

## ほかの案

| 案 | 選ばなかった理由 |
|---|---|
| Workers の有料プラン | 月の料金がかかる。費用 0 の方針に合わない |
| R2 に動画を置く | 無料の枠を超えると、止まらずに請求される |
| Terraform で設定を持つ | wrangler の設定で足りる。状態（state）を置く場所が要る |

## 影響

- 枠を超えた日は `/media/*` がエラーになり、動画が流れない。保存した講座は、通信なしで見られる
- 1 日の回数の枠は、保存・途中への移動・再試行・あとで足す AI チャットも使う
- 有料の機能（有料プラン・有料の置き場所など）を入れるときは、この ADR を置き換える新しい ADR を先に書く
- AI チャット（M4）の利用料は、この決定の外。運営の API キーで払い、守り（1 日の予算・回数の制限など）は M4 の ADR で決める
- ドメインの更新は持ち主が管理する（更新の時期は公開の文書に書かない）
- 同じ決まりを書いている所: [AGENTS.md](../../AGENTS.md) の「公開と Workers のきまり」、[初回の設定](../operations/setup.md)
