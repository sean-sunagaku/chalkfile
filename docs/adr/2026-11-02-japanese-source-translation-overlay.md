# 日本語の台本を正本にし、訳は上書きで重ねる。英語と中国語の声は Kokoro-82M

- 状態: 採用
- 決めた日: 2026-11-02
- 関連: Linear の SUN-1630（M3）、#12
- 作り方の正本: スキルの [i18n.md](../../.claude/skills/study-video-course/references/i18n.md)

## 背景

- 2026-11-02 に、講座を英語と中国語（簡体字）でも出すことにした。声・画面の文字・図の文字・字幕・講座サイトまで、言語ごとに切り替える
- 公開している日本語の動画・時刻・字幕・音声は変えたくない。変えると、全部の書き出し直しと、保存した人の取り直しになる
- お笑い版は、直訳では笑えない

## 決めたこと

- 日本語の台本（`content/<講座 ID>/<レクチャー ID>.ts`）を正本にする。訳は、上書きのファイル（`content/<講座 ID>/<言語>/`）を重ねて作る（重ね方は `content/i18n.ts`）
  - 場面と画面の要素は、日本語と同じ数・同じ順で、文字だけを上書きする。色・アイコン・座標・URL・クイズの答えの番号は、日本語のものを使う。数が合わないと止まる
  - 台詞は丸ごと書き直す。お笑いは、言語ごとに作り直す
  - 訳には、訳したときの日本語の台本の指紋を持たせ、台本が変わったら知らせる
- 英語と中国語の声は、手元で動かす Kokoro-82M（英語は `hexgrad/Kokoro-82M`、中国語は `hexgrad/Kokoro-82M-v1.1-zh`）にする。日本語は VOICEVOX のまま
- 日本語の出力（動画・時刻・字幕・音声の鍵）は変えない

## 理由

- 日本語の出力を変えずに、訳を足せる。#12 では、日本語の台詞の音声と時刻、静止画が、多言語にする前とバイト単位で同じだった
- 訳で変えられるのは文字と台詞だけなので、画面の作りが言語ごとにずれない
- 台詞を丸ごと書き直せるので、笑いを言語ごとに作り直せる
- Kokoro-82M は手元で動き、重みは Apache-2.0。利用料と API キーが要らない。英語と中国語のモデルがある
- 役ごとの声は、2026-11-02 に、同じ文を候補の声で読ませ、Whisper の聞き取りと声の高さで比べて選んだ（`scripts/voices.ts`）

## ほかの案

当時の記録とコードから分かる範囲で書く。

| 案 | 選ばなかった理由 |
|---|---|
| 言語ごとに台本を丸ごと写す | 画面の作り・URL・クイズの答えが、言語ごとにずれる。直すときに、全部の言語を直すことになる |
| 機械翻訳で、訳を自動で作る | お笑いが直訳になる。言葉遊びは作り直す必要がある |
| クラウドの音声合成を使う | 利用料と API キーの管理が要り、費用 0 の方針（[Workers Free のままにする](2026-11-02-workers-free-only.md)）に合わない |

## 影響

- 訳の講座のずんだもんの声は、VOICEVOX のずんだもんではない。講座の `sourceNote` とクレジットに書く
- Kokoro のモデルは、初めて使うときに手元に取ってくる。読みは Whisper で聞き取り直して確かめる（`scripts/check_speech.py`）
- 読む教材（`material`）と章の計画（`syllabus`）は、日本語だけで出す
- 訳を公開するかは、`site/config.json` の `publishLangs` で決める。訳は M3 で、新しい配信（Worker と Releases）から出す
- 訳を公開する前に、人が訳の自然さ・笑い・中国語の読みを確かめる
