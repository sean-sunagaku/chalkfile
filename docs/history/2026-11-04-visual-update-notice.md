# 動画の見た目の更新のお知らせ（2026-11-04・公開準備）

これは記録。全 9 講座の日本語の動画 60 本（字幕版を含む）とポスター 48 枚を作り直し、[講座のページの更新](2026-11-04-course-page.md) と同じ回に公開する。講座サイトの「新しい版」の案内と、[変更の記録](../../CHANGELOG.md) にもまとめる。公開の順番は [公開の順番](../operations/publish.md)。

台詞・声・動画の長さ・場面の並びと中身は変えていない。変えたのは、画面の文字の読みやすさと、部品の見た目だけ。

## 変わること

| 何が | どう変わるか | 理由 |
|---|---|---|
| 書体 | 字形はそのまま。書き出すときに、手元の書体のファイル（台本とサイトの文字を入れたもの）を使う | 書き出すたびに、ネットから書体を取らなくてよくするため（同じ字形になることも確かめやすい） |
| 小さな文字 | 出典・注意書き・クレジット・レクチャーの番号・図の補足・札などを、1〜3px 大きくする（本文は 26px 以上、札と補足は 22px 以上） | 小さな画面でも読めるようにするため |
| 見出し・字幕・図の名前 | 1 行に入らないときは、文字の幅を測って入るまで縮める。字幕は帯の 2 行に入るまで縮め、3 行のはみ出しが無くなる | 英語の見出しや長い台詞が、画面の外や字幕の帯の外にはみ出していたため |
| 文字の色 | 出典・注意書き・クレジットなどの補足の文字を濃くする。図の色の文字の一部（黄色・水色・緑など）を濃くする。字幕の名前札・丸の中の数・まとめの番号を、読める色にする | 地の色とのコントラストが、読みやすさの目安（本文 4.5・大きい文字 3.0）に届いていなかったため |
| スマホの枠・窓の信号 | 2 種類ずつあったものを、1 種類にそろえる（画面の図のスマホの角が少し丸くなり、ブラウザの窓の信号の色が、コードの窓と同じになる） | 同じものを同じ形で見せるため |
| コードの色分け | 言語ごとに色を分ける（TypeScript のコメント・`const`・`=>` に色が付く。text と書いたコードは色を付けない） | Python の決まりを、ほかの言語にも当てていたため |
| アイコン | lucide-react の新しい版にし、27 個のアイコンの形が少し変わる | 部品の版を上げたため |
| 矢印の動き | やりとりの図の矢印の光の粒を、ほかの図の矢印と同じ速さにする | 動きをそろえるため |

## 保存した人へ（講座サイトの案内に出す文の下書き）

> 動画の見た目を新しくしました（文字を読みやすくし、はみ出しを直しました。台詞と長さは前と同じです）。保存した講座は、「新しい版」の案内から更新すると、動画を取り直します。取り直すまでは、前の動画をそのまま見られます。

- 保存した人は、更新すると全部の動画を取り直すことになる（動画のファイルが新しくなるため）。取り直す大きさは、保存した講座の動画の分
- 前の動画は Releases に残し、Worker の `retained` で一定の期間は配る（[ADR](../adr/2026-11-02-keep-old-video-hashes.md)）

## 出すときに確かめること

- 全部の動画の静止画を、前の版と比べて見る（`npm run stills:compare`。字幕つきは `--captions`）
- 書き出しにネットが要らないこと（書体を Google Fonts から取らない）
- 書き出し直した動画の長さが、timeline と同じこと（台詞と声は変えていない）
