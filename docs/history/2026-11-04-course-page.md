# 講座のページの作り直しのお知らせ（2026-11-04・下書き）

これは記録。書いた日のことで、今の手順ではない。今の仕組みは、保存が [保存の設計](../architecture/offline.md)、配り方が [配信の設計](../architecture/delivery.md)、学ぶ人への説明が [学ぶ人向けの説明](../guide/learner-offline.md)。

講座のページの画面（HTML の中の JS）と、保存の画面を作り直す回のお知らせ。全講座のページの版（pageVersion）が変わる。動画とポスターの画像は変わらない。公開する日が決まったら、この文書の日付と、サイトの「新しい版」の案内に出す文（`site/news.ts` の `date`）を、公開する日にそろえる。

## 変わるもの

| もの | 変わること |
|---|---|
| 講座のページの画面 | `site/template.html` の中の JS を TypeScript の役割ごとのファイル（`site/course-page.ts`・`site/page/`）にし、組み立てで 1 本にまとめて、縮めてページに入れる。保存版の HTML が 1 枚で完結するのは前と同じ |
| 学習の記録 | localStorage の形に版の番号 `v` を入れる。鍵と値の形は前と同じなので、前の版のページも読める |
| キーボードと読み上げ | 本文へ飛ぶリンクと `<main>`。タブを ← → と Home・End で移れる。クイズに答えると解説へフォーカスが移る。再生中もカリキュラムのフォーカスが飛ばない。1 文字のショートカットは、動画を選んでいるときだけ効く。保存の進み具合の読み上げは 10% ごと |
| 文字の色 | 薄い文字（時刻・数・注記）を、どの面でもコントラスト比 4.5 以上の濃さにする（サイトだけ。動画の色は変えない） |
| 保存の初めの案内 | 初めて開いたとき、Service Worker が動き出す前に保存状態を問い合わせて「保存機能を準備できません」が残る誤りを直す |
| 無効にした保存版 | 重大な不具合で無効にした版を保存した人には、オンラインで開いたとき、更新して保存する案内だけを出す（合わない「保存版が切り替わりました」を出さない） |
| 「新しい版」の案内 | 何が変わったかを短く出す（文の正本は `site/news.ts`。講座の保存用の教材情報 `offline-manifest.json` の `news` に入る） |

## 学ぶ人に起きること

- 講座を保存した人には、講座を開いて「更新を確認」すると「新しい版があります」が出る。この回の前に保存した版の画面には、何が変わったかの文は出ない（何が変わったかを出す画面は、この回の画面から）
- 「新しい版に更新して保存」を選ぶと、ページとポスターだけを取り直す。動画は、前の保存版から写す（取り直さない）
- 更新するまでは、前の保存版がそのまま使える。オフラインでも再生できる
- ノート・進み具合・クイズの答え・再生の好み（localStorage）は、そのまま読める
- Service Worker を入れた人には、「アプリの更新があります」が 1 回出る（一覧のページなど、起動用のファイルが変わるため）
