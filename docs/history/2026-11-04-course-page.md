# 講座のページの作り直しのお知らせ（2026-11-04・下書き）

これは記録。書いた日のことで、今の手順ではない。今の仕組みは、保存が [保存の設計](../architecture/offline.md)、配り方が [配信の設計](../architecture/delivery.md)、学ぶ人への説明が [学ぶ人向けの説明](../guide/learner-offline.md)。

講座のページの画面（HTML の中の JS）と保存の画面を作り直し、サイトの決まった文字・検索・無いページ・アプリの manifest・動画の読み方・声のクレジット・キャッシュを直す回のお知らせ。2 つの branch（画面と読み上げの直し・文字と検索と配り方の直し）を、1 回で出す。全講座のページの版（pageVersion）が変わる。動画とポスターの画像は変わらない。公開する日が決まったら、この文書の日付と、サイトの「新しい版」の案内に出す文（`site/news.ts` の `date`）を、公開する日にそろえる。

## 変わるもの

| もの | 変わること |
|---|---|
| 講座のページの画面 | `site/template.html` の中の JS を TypeScript の役割ごとのファイル（`site/course-page.ts`・`site/page/`）にし、組み立てで 1 本にまとめて、縮めてページに入れる。保存版の HTML が 1 枚で完結するのは前と同じ |
| 学習の記録 | localStorage の形に版の番号 `v` を入れる。鍵と値の形は前と同じなので、前の版のページも読める |
| キーボードと読み上げ | 本文へ飛ぶリンクと `<main>`。タブを ← → と Home・End で移れる。クイズに答えると解説へフォーカスが移る。再生中もカリキュラムのフォーカスが飛ばない。1 文字のショートカットは、動画を選んでいるときだけ効く。保存の進み具合の読み上げは 10% ごと |
| 文字の色 | 薄い文字（時刻・数・注記）を、どの面でもコントラスト比 4.5 以上の濃さにする（サイトだけ。動画の色は変えない） |
| 保存の初めの案内 | 初めて開いたとき、Service Worker が動き出す前に保存状態を問い合わせて「保存機能を準備できません」が残る誤りを直す |
| 無効にした保存版 | 重大な不具合で無効にした版を保存した人には、オンラインで開いたとき、更新して保存する案内だけを出す（合わない「保存版が切り替わりました」を出さない） |
| 「新しい版」の案内 | 何が変わったかを短く出す（文の正本は `site/news.ts`。講座の保存用の教材情報 `offline-manifest.json` の `news` に入る） |
| サイトの決まった文字 | 言語ごとのファイル（`site/i18n/`）にする。日本語の文は前と同じ。ページに入れる文字を、そのページが使うものだけにする（講座のページの JSON と保存の画面の JSON に、同じ表を 2 回入れていた） |
| JS が無くても読める | 講座のページの HTML に、最初のレクチャーの見出し・要約・注意書き・要点・チャプターと、カリキュラム・本数と長さ・クレジット・注意書き・リンクを書く（画面は動き出すと、学習の記録に合わせて描き直す） |
| 検索 | `sitemap.xml` と `robots.txt` を置く（robots は `/media/` と `offline/` を取りに来させない） |
| 無いページ | 言語ごとの 404 にし、見出しと案内を `<main>` に入れて、短い案内の文を足す |
| アプリ | Web App Manifest を言語ごとにする（今は日本語だけ）。アイコンを `any` と `maskable` の別の画像にする（`maskable` の画像を足す）。日本語のアプリの id・start_url・scope は前と同じ |
| 動画の読み方 | 講座を開いただけでは、動画を読まない（`preload="none"`）。再生を押すか時刻を選んだときに、開いたレクチャーの動画だけを読む。カリキュラムの長さは前と同じく台本のデータから出す |
| 声のクレジット | お笑い版の講座のページと一覧のページのクレジットに、ずんだもんと玄野武宏も出す（台詞の声から作る）。講座の `sourceNote` に手で書いていた声の文は外す |
| キャッシュ | 講座のポスターを、`?v=` の付いた資源として 1 年キャッシュさせる（2 回目に開いたとき、取り直さない）。一覧のページの縮小画像と og:image にも `?v=` を付ける |
| 旧 Pages の名残 | 言語ごとの動画のサイトの設定（`site/config.json` の `media`）と、その分岐を消す。公開物の `.nojekyll` も作らない |

## 学ぶ人に起きること

- 講座を保存した人には、講座を開いて「更新を確認」すると「新しい版があります」が出る。この回の前に保存した版の画面には、何が変わったかの文は出ない（何が変わったかを出す画面は、この回の画面から）
- 「新しい版に更新して保存」を選ぶと、ページとポスターだけを取り直す。動画は、前の保存版から写す（取り直さない）。取り直す量は、講座ごとに 134,107〜921,679 B（全 9 講座で 4,314,120 B）。写す動画は全 9 講座で 879,276,298 B
- 更新するまでは、前の保存版がそのまま使える。オフラインでも再生できる
- ノート・進み具合・クイズの答え・再生の好み（localStorage）は、そのまま読める。新しい画面は、書き直すときに形の版の番号を足す（前の画面も読める形のまま）
- Service Worker を入れた人には、「アプリの更新があります」が 1 回出る（起動用のファイルの一覧が変わるため。取り直す起動用のファイルは 23 ファイル・729,237 B）
- 保存していない人は、次に開いたときから新しい画面になる（保存の取り直しは起きない）。動画は、再生を押してから読み始めるので、最初の再生が少し遅れることがある
- お笑い版の講座のページと一覧のページで、使った全部の声のクレジットが見える

## 組み立ての前と後

本物の講座を CI と同じ順（素材の取り出し → `synth --cached-only` → `gen` → `build_site --strict`）で組み、この回の前（main の `6d89b07`。公開物は `5a184e7` と同じ）と後の `site/dist` の SHA-256 を比べた。ファイルは 83 から 86 になった。

- 変わったのは 24 ファイル: 全 9 講座の `index.html` と `offline-manifest.json`・一覧のページ（`index.html`）・オフラインの案内（`offline/index.html`）・`sw.js`・`_headers`・`404.html`・`manifest.webmanifest`
- 足したのは 4 ファイル（`icons/maskable-192.png`・`icons/maskable-512.png`・`robots.txt`・`sitemap.xml`）、消したのは `.nojekyll`（`.assetsignore` で送っていなかった空のファイル）
- `offline-manifest.json` で変わったのは、ページの項目（大きさと SHA-256）・`pageVersion`・ポスターの URL の `?v=`・`revision`・合計の大きさと、足した `news`。動画の項目（60 本）とポスターの中身は前と同じ
- `sw.js` で変わったのは、起動用のファイルの一覧（一覧のページ・オフラインの案内・`?v=` を付けた縮小画像・言語ごとの manifest・`maskable` のアイコン）と、その指紋（`build`）・保存機能のエラーの文の置き場所（設定に入れる）・言語のフォルダの読み方（言語の一覧から）。22,984 B から 24,116 B
- ポスター・一覧のページの画像・ふつうのアイコン（180・192・512）は、前とバイト単位で同じ
- 講座のページは、1 講座あたり 24〜29 KB 小さくなった（画面の script を縮め、ページに入れる文字をそのページが使うものだけにしたため。JS が無くても読める本文を足した分を引いても、たとえば stripe-billing は 241,056 B から 217,024 B）
